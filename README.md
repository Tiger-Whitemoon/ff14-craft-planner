# エオルゼア装備クラフトプランナー

FINAL FANTASY XIV のジョブと現在のレベルを選ぶと、製作できる装備一式と、その製作に必要な素材の合計を表示する非公式Webツールです。手持ちの素材数を入力すると、不足している分だけを計算します。

**公開ページ：** https://tiger-whitemoon.github.io/ff14-craft-planner/

## 主な機能

- ジョブとレベルから、部位ごとにアイテムレベルが最も高い製作装備を自動で選択
- 部位ごとの候補の入れ替え、「作らない」部位の指定
- 中間素材までさかのぼった必要素材の集計
- 所持数の入力による不足数の計算（入力内容はブラウザ内に自動保存）
- 中間素材ごとの「自作する／買う」の切り替え
- 製作手順（どのクラフターで何回作るか）の表示
- 不足素材リストのコピー
- 各アイテムからエオルゼアデータベースの検索結果へのリンク

## 使い方

公開ページをブラウザで開くだけで使えます。インストールやログインは不要です。入力した所持数などは、お使いの端末のブラウザ内にのみ保存され、外部には送信されません。

## データについて

ゲームデータは [XIVAPI](https://v2.xivapi.com/) から取得しています。アイテムの詳細は [エオルゼアデータベース](https://jp.finalfantasyxiv.com/lodestone/playguide/db/) でご確認ください。
